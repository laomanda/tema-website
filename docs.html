Selamat Datang di
Statis Theme Gallery

Statis adalah koleksi berisi 10 tema *front-end* premium yang dibuat secara eksklusif menggunakan HTML murni, CSS/Tailwind, dan JavaScript "Vanilla" statis. Semua direktori sepenuhnya **berdiri sendiri (standalone)** tanpa memerlukan server lokal, build-tools, atau npm untuk segera dilihat.

Teknologi yang Digunakan

HTML5

Kerangka dan Markup semantik bebas error untuk SEO.

Tailwind CSS (CDN)

Layout, *styling*, dan responsivitas. Disertakan via *script CDN* untuk *zero-configuration*.

Struktur Direktori Tema

Setiap tema berada di dalam folder /theme/. Mereka diisolasi agar kode satu tema tidak bertentangan dengan tema lain.

design-theme/
├── index.html          // Hub (Halaman Utama ini)
├── docs.html           // Dokumentasi ini
└── theme/              // Direktori Tema Utama
    ├── anime/          // Tampilan Dunia Otaku Pop-culture
    ├── cyberpunk/      // Estetika Neon & Glitch Tech
    ├── immersive/      // Visual Gelap Paralaks 3D
    ├── kartun/         // Gaya Buku Komik / Superhero
    ├── makanan/        // Desain Restoran / Kuliner hangat
    ├── minimalist/     // Desain Super Bersih ruang kosong lebar
    ├── modern/         // UI Dashboard & Glassmorphism
    ├── monochrome/     // Hitam/Putih kontras tinggi mewah
    ├── neo-brutalism/  // Geometri asimetris warna nyentrik
    └── retro/          // Gaya Vaporwave / Arcade 80's

Menggunakan Tema

1

Buka Halaman Langsung (Tidak Perlu Server)

Cukup Klik Kanan -> Open with Browser pada file index.html apapun di dalam folder tema. Tema akan memusatkan *styling* langsung dari file CDN dan tidak butuh *hot-reloading* NPM.

2

Konfigurasi Tailwind via Script Kustom

Pengaturan spesifik mengenai warna (seperti palet Neon pada Cyberpunk) disimpan dalam tag <script> tailwind.config = {...} </script> di kolom <Head> file HTML masing-masing tema.

Sistem CSS/SVG Placeholders

PENTING: Agar *template* tidak dipenuhi masalah tautan gambar yang terputus (Broken Image Links/404) ketika dibuka secara lokal oleh klien, kami Sengaja TIDAK Menggunakan Tag <img> berisi gambar *Unsplash/Pexels* sama sekali!

Sebagai gantinya, ruang gambar foto telah diganti dengan CSS Gradients, Pattern, SVG Ikon (FontAwesome), dan Typografi Eksentrik. Semua ini meniru estetika aslinya (contoh: blok hijau untuk "Hero" di Brutalisme, Ikon Hantu untuk Karakter Anime, dll.).

Cara menggantinya untuk Project Asli Anda:
Temukan div berlapis CSS tersebut dan ganti blok itu dengan blok <img src="path/to/foto-asli.jpg"> milik klien Anda yang sudah di-*hosting*.
